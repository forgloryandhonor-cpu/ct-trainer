# Тренировка ЦТ

Тренажёр по общей эпидемиологии: 30 случайных вопросов из банка из 125 заданий, строгая проверка выбранных ответов и оценка по 100-балльной шкале. Банк вопросов доступен по темам и через поиск.

## Установка на iPhone

1. Откройте сайт в Safari и дождитесь надписи «Работает без интернета» на главном экране.
2. Нажмите «Поделиться» → «На экран “Домой”». Если появляется переключатель «Открывать как веб-приложение», включите его.
3. Откройте «Тренировка ЦТ» с появившейся иконки. При первом запуске из иконки оставьте интернет включённым до готовности офлайн-режима.

Далее приложение работает без сети, включая рисунки, поиск и новые попытки. Попытка и результат сохраняются локально на устройстве. Веб-версия и Android-приложение хранят попытки отдельно. Удаление данных сайта или приложения удалит сохранённую попытку.

Обновления загружаются при подключении к сети и применяются после закрытия приложения. Текущая попытка не перезагружается. Все три задания без исходных рисунков участвуют в выборке и отмечены соответствующей пометкой.

## GitHub Pages

Это готовый статический сайт. Для публикации в Settings → Pages выберите Deploy from a branch, ветку `main` и папку `/ (root)`. Все пути относительные: сайт работает как в корне домена, так и по адресу `https://<аккаунт>.github.io/<репозиторий>/`.
